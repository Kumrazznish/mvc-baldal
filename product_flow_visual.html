$.ajax({ ... }) HTTP Client
Iska Matlab: Asynchronous JavaScript and XML. Browser me background me bina full web page reload kiye server se communication karne ka mechanism.
File:product.js:L7, employee.js:L9
Properties:url (target endpoint), type (HTTP verb GET/POST), dataType (expected response type), success, error.
Faayda:User ko seamless Single Page App (SPA) experience milta hai, flicker nahi hota.
$.ajax({
    url: "/Product/GetProducts",
    type: "GET",
    dataType: "json"
});
dataType: "json" Config Option
Iska Matlab: jQuery ko batata hai ki server se aane wala raw text string ek JSON format hai, isliye jQuery usko automatically JSON.parse() karke direct JavaScript Object bana de.
Behind Scenes:Agar ye na ho toh response text string format me mil sakta hai jise manually JSON.parse(res) karna padega.
// Server returns raw string: '{"success":true,"data":[...]}'

    console.log(response.data[0].productName); // Direct property access!
}
success: function(response) Callback
Iska Matlab: Jab server HTTP status 200 OK return karta hai, tab ye function execute hota hai. Iske andar response parameter me Controller ka JSON payload aata hai.
Business Check:if (!response.success) check karta hai ki server ne status ok bheja par application level error toh nahi hai (e.g. database down).
success: function (response) {
    if (!response.success) {
        alert(response.message || "Unable to load products.");
        return;
    }
    // Bind to Kendo Grid
}
error: function(xhr) Callback
Iska Matlab: Jab server HTTP error return karta hai (jaise 404 Not Found, 500 Internal Server Error, ya network drop), tab ye callback trigger hota hai.
xhr Object:XMLHttpRequest object jisme status (500) aur responseText rehta hai.
Defensive Code:Code try { JSON.parse(xhr.responseText) } catch use karta hai taaki agar server ne JSON error message bheja ho toh alert me dikh sake.
error: function (xhr) {
    console.error("GetProducts error:", xhr.responseText);
    var message = "Unable to load products.";
    try {
        var res = JSON.parse(xhr.responseText);
        if (res.message) message = res.message;
    } catch (e) { }
    alert(message);
}
escapeHtml(value) Security Sanitizer
Iska Matlab: XSS (Cross-Site Scripting) Prevention. String ke dangerous characters (<, >, ", ', &) ko HTML entities (&lt;, &gt;) me convert karta hai.
File:employee.js:L438-L456
Kyu Jaruri Hai:Agar product name me koi malicious script ho (jaise <script>stealCookies()</script>), toh browser use code samajhkar execute na kare, balki plain text ki tarah display kare!
function escapeHtml(value) {
    if (value == null) return "";
    return String(value)
        .replace(/&/g, "&amp;")
        .replace(/</g, "&lt;")
        .replace(/>/g, "&gt;")
        .replace(/"/g, "&quot;");
}
__RequestVerificationToken Security Token
Iska Matlab: CSRF (Cross-Site Request Forgery) Prevention. ASP.NET Core Razor view me hidden input generate karta hai. AJAX POST request ke sath is token ko bhejna mandatory hota hai.
File:product.js:L177-L196
Kaise Kaam Karta Hai:Server session cookie me ek encrypted key hoti hai aur view ke hidden input me doosri key. Server dono ko compare karke request validate karta hai.
var token = $("input[name='__RequestVerificationToken']").first().val();

$.ajax({
    url: "/Product/Delete",
    type: "POST",
    data: {
        id: productId,
        __RequestVerificationToken: token // Required by [ValidateAntiForgeryToken]
    }
});

grid.destroy() & empty() Memory Management
Iska Matlab: Purane grid component ko memory se clean karna. Agar user refresh kare ya delete ke baad dobara grid bind ho, toh purane event listeners aur DOM nodes ko detach karta hai taaki browser crash ya memory leak na ho.

What happens without it:Purana grid instance duplicate ho jayega ya header repeat hone lagega.
var existingGrid = $("#productGrid").data("kendoGrid");
if (existingGrid) {
    existingGrid.destroy(); // Detaches all widget event bindings
    $("#productGrid").empty();   // Removes all internal HTML nodes
}

excelFile.OpenReadStream() & new XLWorkbook Stream Parsing
Iska Matlab: Uploaded file ko disk par save kiye bina, direct memory stream ke through read karta hai aur XLWorkbook object me load karta hai.
Performance:Disk I/O save hoti hai; temporary file delete karne ka jhanjhat nahi rehta.
using Statement:using var guarantee karta hai ki stream aur workbook process hone ke baad memory automatically dispose ho jaye.

worksheet.LastRowUsed()?.RowNumber() Range Detection
Iska Matlab: Excel sheet ke aakhri us row ka number nikalta hai jisme actually koi data ya value likhi hui hai.
Kyu Smart Hai:Excel sheet me 10 lakh rows hoti hain. Ye pura sheet scan karne ki jagah sirf wahi tak rukta hai jahan tak user ne data fill kiya hai!
Validation:Agar lastRow < 2 hai matlab sheet me sirf header hai ya sheet khali hai.
int lastRow = worksheet.LastRowUsed()?.RowNumber() ?? 0;
if (lastRow < 2) {
    TempData["ErrorMessage"] = "Excel file does not contain product data.";
    return RedirectToAction("Import");
}
worksheet.Cell(row, col).GetString().Trim() Cell Extraction
Iska Matlab: Specific Row aur Column ke cell ka content safe text format me nikalta hai aur aage-peeche ke extra spaces remove karta hai.
Column Mapping:Cell(row, 1) = ProductCode | Cell(row, 2) = ProductName | Cell(row, 3) = Quantity | Cell(row, 4) = Price
Crash Proof:Agar cell blank ho toh GetString() null-safe empty string return karta hai bina crash hue.
for (int row = 2; row <= lastRow; row++) {
    string productCode = worksheet.Cell(row, 1).GetString().Trim();
    string productName = worksheet.Cell(row, 2).GetString().Trim();
    string quantityText = worksheet.Cell(row, 3).GetString().Trim();
    string priceText = worksheet.Cell(row, 4).GetString().Trim();
}
int.TryParse() & decimal.TryParse() Safe Type Casting
Iska Matlab: Text ko number me convert karne ka safe tareeka. Agar user ne quantity me galti se text likh diya (jaise "Ten" ya "abc"), toh program crash nahi hoga, balki false return karega aur error count me add kar dega.
Audit Log:Loop me successCount aur errorCount maintain hoti hai taaki user ko report mile ki 100 me se kitne rows import hue aur kitne fail hue.
if (!int.TryParse(quantityText, out int quantity) || quantity < 0) {
    errorCount++;
    continue; // Skip bad row without crashing whole batch!
}

if (!decimal.TryParse(priceText, out decimal price) || price < 0) {
    errorCount++;
    continue;
}

row["Col"] == DBNull.Value SQL Null Checker
Iska Matlab: SQL Server ka NULL C# ke standard null ke barabar nahi hota! ADO.NET me database ke NULL value ko System.DBNull.Value singleton object se represent kiya jata hai.
Why Critical:Agar direct Convert.ToInt32(row["Quantity"]) kiya aur database me NULL hua, toh 0 aayega par (int)row["Quantity"] se seedha InvalidCastException crash hoga! Isliye check zaroori hai.
productCode = row["ProductCode"] == DBNull.Value 
    ? "" 
    : row["ProductCode"].ToString();

quantity = row["Quantity"] == DBNull.Value 
    ? 0 
    : Convert.ToInt32(row["Quantity"]);
SqlDataAdapter.Fill(dataTable) Bridge Adapter
Iska Matlab: ADO.NET ka bridge component jo SQL Server se connection open karta hai, command execute karta hai, incoming TDS byte streams ko read karke DataTable me rows create karta hai, aur automatically connection close/return karta hai!

DataTable dataTable = new DataTable();
adapter.Fill(dataTable); // Opens, executes, populates, and closes!
return dataTable;
dbo.SP_Product_GetAll Stored Procedure
Iska Matlab: SQL Server level compiled database procedure. Direct SQL string query likhne se behtar SP execute hota hai kyuki ye pre-compiled rehta hai aur SQL Injection se 100% immune hota hai. 
CREATE OR ALTER PROCEDURE dbo.SP_Product_GetAll
AS BEGIN
    SET NOCOUNT ON;
    SELECT ProductId, ProductCode, ProductName, Quantity, Price, ImagePath, IsActive
    FROM dbo.Products
    WHERE IsActive = 1           -- Soft delete filter
    ORDER BY ProductId DESC;     -- Newest first
END;
